# coi-formularze

Paweł's HackNation 2026 solution to the COI "Cyfryzacja Formularzy" task: a REST API that turns a blank paper form (PDF, DOC, DOCX, ODS, XLSX, XLS, JPG, PNG) into an importable COI e-service JSON. Everything runs locally: an open-weights model in Ollama, no cloud.

## Pipeline (`app/pipeline.py`)
file → text (`app/extract/`; `PIPELINE=images`: page images → Markdown by a vision model, `app/llm/transcribe.py`) → model plan (`app/llm/planner.py`, contract `app/plan.py`) → quote filter (`app/quotes.py`) → builder (`app/builder/`, Plan → COI JSON) → rules check (`app/rules.py`). The model understands the paper, code owns the COI format.

## Layout
- `app/api.py` REST: `GET /api/auth/config`, `POST /api/auth/token`, `POST /api/forms/convert` (`?evidence=1` → `{coi, evidence}` for the upload page: paper quotes in the preview and the editor), `POST /api/forms/text` (the text read from a file, no model: the upload page shows it as the original of DOC/DOCX/ODS/XLSX/XLS), `POST /api/forms/check` (COI JSON → rules problems in Polish with the element id, `app/problems.py`), `GET /api/forms/blank` (`{coi, evidence}` of a form built by hand, no file and no model: `builder.blank`, the standard pages around one page with one field, its own elements marked `clerk`), `POST /api/forms/jobs` + `GET /api/forms/jobs/{id}[/result]` (`app/jobs.py`: the same upload in the background on its own 2-thread pool, max 20 pending → 429; the result URL is 404 until done, then the COI JSON or the sync error code via `app/errors.py` `conversion_error`, shared with `convert`; in memory, 1 h after the end), `POST /api/dictionaries/proposals`, `/api/dictionaries` (catalog, `app/catalog.py`), `GET /health`, `/` upload page, `/preview`, `/editor.js`; dev-only `/review` (`app/review.py`, 404 unless `REVIEW_RUNS_DIR` is set).
- `app/history.py` upload page history in SQLite (`HISTORY_DB`, default `history.sqlite3`, gitignored): `GET/POST/DELETE /api/history`, `GET /api/history/{id}/file`, `PUT/DELETE /api/history/{id}`, "Źródło": `POST /api/history/{id}/sources` (body `{coi, evidence}` as the page holds them now → element id → place on paper; the paper's word boxes cached per record) and `GET /api/history/{id}/page/{n}.png` (page ~1600 px, lru_cache + Cache-Control); `index.html` keeps no history in the browser any more, so results from scripts and other browsers show up at :8010. Add a finished conversion from a script: `uv run python -m bench.history_add <original> <coi.json> [--evidence ev.json] [--name label]` (writes the DB directly).
- `app/config.py` settings from env/`.env` (`from app.config import settings`); `app/security.py` JWT (own issuer or JWKS), switched by `AUTH_ENABLED` (default 0 = open API, pages skip the login after asking `GET /api/auth/config`; 1 = Bearer JWT required, login shown); `app/upload.py` in-memory upload, size cap, name/extension/magic-byte checks. `HISTORY_ENABLED` (default 1; 0 = `/api/history` 404 via a router dependency in `api.py`, `GET /api/auth/config` says `history: false`, the page skips every history call and keys documents by `docKey`).
- `app/plan.py` the Plan contract between model and builder; every field, condition and statement carries a `quote` from the paper.
- `app/extract/` bytes → normalized text: `pdf.py` (pages with a missing or garbled text layer go to OCR), `doc.py` (own Word 97 parser), `docx.py`, `sheets.py` (XLSX/XLS/ODS), `ocr.py` + `scan.py` (Tesseract with preprocessing), `layout.py`, `normalize.py` (same form, any format → same text).
- `app/llm/client.py` one OpenAI-compatible JSON-Schema chat call (`LLM_BACKEND`, `LLM_BASE_URL`, `LLM_MODEL`, optional `images` as `image_url` data-URL parts); `planner.py` two passes (structure, then conditions); `prompts/` prompt texts and examples.
- `app/llm/transcribe.py` `PIPELINE=images` (default `text`): every format → page images (pypdfium2; office files via LibreOffice headless → PDF) → one vision call per page at `TRANSCRIBE_SIDE` 1024 px, system prompt `app/llm/prompts/transcribe.md`, presence_penalty 1.5 (stops Qwen copying dot lines forever), `TRANSCRIBE_TIMEOUT_S` 180 + one retry → Markdown the planner reads (`Document.method` `vlm-md`); `bench/transcribe_sides.py` = page-size sweep by gold-quote recall.
- `app/llm/vision.py` page images for a vision model, behind `LLM_VISION` (default off = text-only requests, unchanged): PDF pages (pypdfium2) and JPG/PNG (stacked pages cut) at `LLM_VISION_MAX_SIDE` 1400 px, first `LLM_VISION_MAX_PAGES` 8; both passes get them before the text, pass 2 at `LLM_VISION_CONDITIONS_SIDE` 1024 (0 = none), plus `prompts/vision.md` / `vision_conditions.md`. Quotes still come from the text. `LLM_VISION_TEXT=0` = images instead of the text when every page has one (`vision.images_only`, prompts `vision_only*.md`; quotes from the model's reading, filter at `THRESHOLD_OCR` via `quotes.threshold_for`); `LLM_VISION_GRAY=1` = grayscale pages. `OCR_VLM_MODEL` unset = `LLM_MODEL`.
- `app/quotes.py` drops plan items whose quote is not on paper, fields of the generated pages (also the applicant's own address "Adres zamieszkania / siedziby"; attachments and "wypełnić jeżeli ..." fields stay under such titles), negated conditions over every option of their trigger (before the repairs), and broken conditions (also ones whose quote only repeats the trigger's own question or option while the target is elsewhere on paper, `_supported`); a trigger found after its target is moved right before it (`_hoist_triggers`); `quote_lines` = where a quote sits on the paper; `place_quotes` = the one walk in form order (a repeated label resolves to the occurrence after the previous quote) behind both the paper headings and "Źródło".
- `app/sources.py` "Źródło" (code only): the file's real lines with word boxes (PDF text layer via pypdfium2, normalized to the CropBox with /Rotate; Tesseract psm 11 on plain grayscale pages without a usable layer and on JPG/PNG pages cut by `split_pages`; DOC/DOCX/ODS/XLSX/XLS = the `/api/forms/text` lines), `locate(paper, coi, evidence)` → `{page, pages, boxes}` (one box per printed line, fractions of the page) or `{lines, text}` or null = not found, `condition` for a condition's own quote; a section without a quote gets the place of its paper heading (`_heading_places`, the line `app.headings` names, so "Źródło" shows where "W dokumencie: ..." came from); `page_png`. Measured on gold quotes: PDF 166/166, DOCX 142/142, PNG 161/161 (160 in the PDF's place).
- `app/headings.py` paper heading of every page and section (code only): the nearest heading line (Markdown `#`, "C. ...", "D.1 ...", capitals) above the section's own quote (address blocks) or first field quote, plus its paper page, read from the file's real lines (`app.sources.read_paper`; the planner's Markdown only when the file gives none); `pipeline.convert_with_evidence` adds `heading`/`heading_page` to the evidence, `preview.html` shows "W dokumencie: ..., str. N" under the "Pokaż cytaty" switch, a click jumps the original (PDF page, marked line in DOC/XLSX text; `showPaper` in `index.html`).
- `app/repair.py` deterministic repairs, called inside `filter_plan` before the condition check: options not on paper dropped (a SELECT with any invented option becomes a TEXT_FIELD), a choice question asked twice kept once, a field read twice kept once (an identical field later in its section, or opening the next section when that one repeats the title and has fields of its own; a block printed twice stays; stacked JPG/PNG pages overlap 4% at each cut, `app/extract/scan.py` `split_pages`), the applicant's "Adres do korespondencji" section gets a Tak/Nie question + condition when the paper says "inny niż", else it is dropped (the Dane page has the address).
- `app/builder/` Plan → COI JSON, deterministic (`build_with_evidence` also maps every COI element id to its paper quote, or says model/code made it): `core.py` building blocks, `standard.py` predefined pages from the COI Standards (Dane, Kontakt i zgody, finish; every phone TEXT_FIELD, contact page and subject pages, gets a SELECT "Numer kierunkowy" right before it with `dictionaryName` "Numery kierunkowe" (Słowniki doc; no reference uses it, name by analogy with "Kraje", Paweł's accepted risk; default `["+48"]`, the doc's own example item written like the Kraje default `["Polska"]`), same SHOW condition and REQUIRED, skipped when the section already asks for a "kierunkowy"; TERYT is `TERYT_4G_DOWODOWY` in every address block on purpose: the references disagree, form 1 gives the own address `TERYT_DOWODOWY`, form 5 gives "Adres zamieszkania innej osoby" `TERYT_DOWODOWY`, 4 of their 6 TERYT fields use 4G, so one fixed name cannot match both), `texts.py` verbatim HTML texts, `registry.py` bonus I on subject pages: code (never the model) feeds a field from PESEL / PESEL_ADDRESS only via allow-lists: the label is exactly a registry attribute (data/miejsce/kraj urodzenia, obywatelstwo, nazwisko rodowe, drugie imię, imię ojca/matki; address section exactly "Adres (stałego) zameldowania wnioskodawcy" / "Twój adres...", permanent only) and the applicant is named by the label or by a section title that is exactly an applicant heading ("Dane wnioskodawcy", "Twoje dane"...), never by the page title; the address title may carry only "(stały)", "(aktualny)", "(na pobyt stały)" or "(jeśli posiada)"; any other person (also in another field of the same section), a second applicant, a repeating section, an attribute (or address section) found twice, a conditional or alternative-address description (an address links only with no description on the section or its lines), corrected or changed data, or a form that changes the registration, PESEL data or citizenship means no link. Read-only and without validators (the register may lack the value); while proxy filing is possible it shows only for "Swoim" with an editable `_inna_osoba` twin. Phone stays a TEXT_FIELD.
- `app/rules.py` COI JSON Schema + "Reguły techniczne" checker, `check(coi)` → list of problems.
- `app/dictionaries.py` + `app/llm/dictionaries.py` bonus II: new dictionary proposals next to the COI JSON, model proposes, code filters.
- `app/catalog.py` dictionary catalog in the history SQLite (`/api/dictionaries`, page `/slowniki` = `app/static/dictionaries.html`): COI dictionaries read-only, ours {code, name, sources, items}; "Dodaj" in the "Słowniki" tab stores a proposal and binds its field through the editor (`coi-bind-dict`, undoable; JSON holds only `dictionaryName`); preview.html reads values via `CATALOG` (refreshed on focus, on the page's `coi-catalog` localStorage ping and per document); new conversions never bind on their own.
- `app/static/index.html` upload page: history, batch, ZIP; original | e-service pane with the views "Podgląd", "JSON", "Słowniki" (bonus II panel); there is no edit mode or tab: the editor is the "Edycja" sidebar inside the preview; the history column is always visible (Paweł 21.11 ~23:19) and the layout history | original | form + sidebar is responsive (`layoutPanes`, checked at 1920x1080, 1536x864, 1440x900, 1366x768, 1280x720): when room runs out the original pane gives way first, narrower and then a one-click strip (`coi-original` in localStorage; also automatic when the open sidebar, whose pane takes at least 820 px, leaves it under 400 px, and bringing it back then collapses the sidebar via `coi-close`), never the history and never the form; below 1000 px everything stacks, a failed file has "Spróbuj ponownie", a file dropped anywhere on the page is an upload; a COI JSON dropped there (e.g. from another system) and "+ Zacznij od pustego formularza" (`/api/forms/blank`) skip the model and open done in the editor, without an original pane (`openReady`, `.no-paper`; the history keeps the JSON as its file, no "Źródło"); `app/static/preview.html` e-service preview (bonus V): every step opens without filling ("Dalej" never validates, only "Wyślij wniosek" lists what is missing), two switches, both default on and both turned on when the sidebar opens: "Pokaż cytaty" (body `notes`) draws under each element its paper quote, "W dokumencie" heading and "Źródło", "Pokaż warunki" (body `conds`) its SHOW condition (`notesOf`, `.src.cond` lines) and shows hidden elements as one dashed line (`ghostOf`); ## Commands
- Tests: `uv run pytest` (fast, ~10 s: skips the 17 OCR tests marked `slow`); OCR only `uv run pytest -m slow` (~55 s); everything `uv run pytest -m ""`. Run the slow ones after touching `app/extract/` or `app/sources.py` OCR paths.
- End to end: `uv run python -m bench.run_all [--forms 1,5] [--formats pdf] [--bip] [--out bench/runs/<name>]` (uses the local model); `--rebuild --out <earlier run>` re-runs only the builder on cached plans, never the model (files without one: "not cached"); forms 1 and 5 print `walid=` (validator F1 vs `gold/coi/`, matched fields only, `(+N unscored)` = gold validators on unmatched fields) next to `ref=`
- Input matrix (model x vision input, uses the local model, one arm after another): `uv run python -m bench.matrix --screen` (forms 1,4,5,7, PDF + PNG) or without `--screen` (9 forms); `--arms vl-img,vl-img-gray`, `--formats`, `--resume bench/runs/matrix-<time>` skips done files; stops other Ollama models before each arm and refuses to start next to another bench (`--force`)
- Post-model rules offline (no model): `uv run python -m bench.refilter coi bench/runs/<run> [--out <dir>]`, `... dir bench/runs/<run_dir run>`, `... gold`
- Score one file: `uv run python bench/score.py coi|plan <ours.json> <ref.json>`
- Blind A/B of two finished runs (no model; `run_all` and `run_dir` layouts): `uv run python -I bench/blind.py make --a <old run> --b <new run> --out <dir> [--only 1/pdf,4/pdf]` writes `<dir>/<id>/` (original pages, extracted text, `X.md`/`Y.md` in random order; `=` marks identical outputs, no judge needed) and `<dir>/key.json` (judges never read it); judges follow `bench/JUDGE-BLIND.md` and record with `... blind.py add <dir> <id> --verdict X|Y|tie --defects-x N --defects-y N --reasons "..."`; `... blind.py report <dir>` unblinds into `<dir>/REPORT.md` (wins A/B/ties, defects, worst regressions first)
- Dev server: launchd agent `com.pawel.coi-api` keeps the API on http://localhost:8010 (no login while `AUTH_ENABLED` is 0; with 1 login admin / haslo, `--reload` on `app/`), log `~/Library/Logs/coi-api.log`. Restart: `launchctl kickstart -k gui/$(id -u)/com.pawel.coi-api` (after a plist env change: `launchctl bootout gui/$(id -u)/com.pawel.coi-api`, then `bootstrap gui/$(id -u) <plist>`, kickstart keeps the old env). Its plist sets `REVIEW_RUNS_DIR=~/coi-formularze/bench/runs`, so the review page is http://localhost:8010/review (unset in Docker). Never put `--` inside an XML comment in its plist (a heartbeat check parses it with plistlib).
- Native run, Docker, config table, API: `README.md` (jury-facing, keep it human).
