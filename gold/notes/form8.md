# Form 8: deklaracja o opłacie za odpady (Gdynia) - gold plan notes

- Applicant: person + entity (wspólnota, spółdzielnia, "Nazwa pełna", NIP/REGON "dot. tylko osób prawnych"), PESEL yes, proxy yes (objaśnienie 13: pełnomocnictwo + 17 zł opłata skarbowa; the Dane page stamp-duty block covers it). B.1.2-4 (name/PESEL/NIP), B.3 address and H.74-75 signer name all live on the code-built Dane page.
- Dropped: legal basis, "Składający"/"Termin składania" header (no data), A. organ address (-> addressee), F.70-71 (contact page), H date/signature, I. "Adnotacja organu" (official's part), G.73.3 "Dokumenty upoważniające" (Dane page proxy upload), RODO text, objaśnienia 1-5 (instructions about paper/IDs).
- B.1.1 six roles -> SELECT (>5 options per Standards). Role 6 "(należy podać jaki oraz dokładne dane)" -> TEXTAREA shown for it. Role 2 "współwłaściciel (wspólność majątkowa)" -> shows B.2 spouse section (name/PESEL/address split) and a TEXT_BLOCK that the spouse must sign too (from poz. 78 "Podpis współmałżonka (wypełnić tylko w przypadku zaznaczenia poz. B 1.1.2)").
- B.3.16 "Numer/y działki (wypełnić jeżeli nieruchomość nie ma urzędowo nadanego adresu)" and B.4 "(wypełnić tylko w przypadku kiedy jest inny niż w poz. B.3)" have no trigger on paper -> synthesized Tak/Nie RADIOs. B.4 keeps the paper's address fields (Kraj, Województwo, Gmina, ...) as TEXT_FIELDs; the builder should ideally swap them for the Standards address block with dictionaries.
- C.25 four circumstances -> RADIO; each date box -> DATEPICKER shown for its option (one "Data zmiany danych" serves both "nowa deklaracja" and "korekta", the paper uses the same wording). Objaśnienie 6 -> hint on the first date.
- D.3 moved before D.2 so it can drive it: D.2 (container location) only for multi-unit buildings, plus a synthesized RADIO from objaśnienie 8 ("odrębnie na daną część budynku lub odrębnie na dany budynek").
- D.4.35 compost "Oświadczam..." is NOT a consent statement: it is optional, applies only to single-family houses and switches the fee table, so it is a RADIO shown for "jednorodzinny". A mentor might want it worded as an oświadczenie in a CONSENT_SECTION instead.
- E.1 vs E.2: E.2 shown when compost = Tak, E.1 otherwise (negate), so multi-unit buildings always get E.1. Fixed rates (poz. 37, 40, ... 65) are not fields, they are in each count field's hint. Every count, row amount, exemption and subtotal stays a NUMBER (paper positions the tax system expects), no computed logic; only subtotals and E.4 total are required.
- D.3.34 TAK -> E.3 amount (objaśnienie 12) and required upload "Załącznik A lub B" (one uploader, the A/B choice is in the hint; conditions cannot AND type x TAK).
- Pouczenie (declaration = executable title) kept as a TEXT_BLOCK next to the total: unfavourable but necessary info (Standards "Rzetelność"). Objaśnienie 7 (one declaration per property) kept as TEXT_BLOCK.
- F.72 e-mail correspondence consent -> optional statement.
- Not kept: objaśnienie 5b (no PESEL -> ID document number and type); the logged-in mObywatel user always has PESEL. Miejscowość in D.1 is pre-printed "GDYNIA" on paper; plan cannot set a default, so it is a required field with a hint.
