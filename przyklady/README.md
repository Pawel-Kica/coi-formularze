# Przykładowe pliki do wypróbowania API

Puste formularze z materiałów zadania COI, te same pliki, które mierzy tabela „Każdy formularz z zadania” w głównym `README.md`. Na obu sędziowie nie policzyli żadnej poprawki urzędnika.

- `formularz-3.jpeg`: skan „Wniosku o wydanie zaświadczenia” (1 strona, około 20 s, 0,012 $). Nasz wynik: `output/api/formularz-3.json`.
- `formularz-2.pdf`: „Wniosek o zwrot opłaty skarbowej” (około 20 s, 0,013 $). Nasz wynik: `output/api/formularz-2.json`.
